ÉTAPE 1 : Créer le dépôt sur GitHub
────────────────────────────────────────────────────────────────────
1. Ouvrez votre navigateur et allez sur : https://github.com
2. Cliquez sur le bouton "+" en haut à droite → "New repository"
3. Remplissez :
   - Nom : plateforme-surveillance-vehicules
   - Description : Système intelligent de reconnaissance de véhicules
   - Visibilité : Public ou Private (votre choix)
   - ⚠️ NE COCHEZ RIEN (pas de README, .gitignore ou licence)
4. Cliquez sur "Create repository"


ÉTAPE 2 : Lier votre dépôt local à GitHub
────────────────────────────────────────────────────────────────────
Ouvrez PowerShell ou CMD dans ce dossier et exécutez :

# Remplacez VOTRE_USERNAME par votre vrai nom d'utilisateur GitHub
git remote add origin https://github.com/VOTRE_USERNAME/plateforme-surveillance-vehicules.git
git branch -M main
git push -u origin main


EXEMPLE CONCRET :
────────────────────────────────────────────────────────────────────
Si votre username GitHub est "john-doe", tapez :

git remote add origin https://github.com/john-doe/plateforme-surveillance-vehicules.git
git branch -M main
git push -u origin main


ÉTAPE 3 : Authentification
────────────────────────────────────────────────────────────────────
Lors du "git push", GitHub va demander :

Option A - Personal Access Token (RECOMMANDÉ) :
1. Allez sur GitHub → Settings → Developer settings → 
   Personal access tokens → Tokens (classic)
2. Generate new token (classic)
3. Nom : "Plateforme Surveillance"
4. Cochez : "repo" (accès complet)
5. Generate token
6. COPIEZ LE TOKEN (vous ne le reverrez plus)
7. Lors du push :
   - Username : votre_username_github
   - Password : COLLEZ_LE_TOKEN (PAS votre mot de passe)

Option B - GitHub CLI (Alternative) :
gh auth login
gh repo create plateforme-surveillance-vehicules --public --source=. --remote=origin
git push -u origin main

═══════════════════════════════════════════════════════════════════════
  PROBLÈMES COURANTS ET SOLUTIONS
═══════════════════════════════════════════════════════════════════════

❌ Erreur : "remote origin already exists"
✅ Solution :
   git remote remove origin
   git remote add origin https://github.com/USERNAME/plateforme-surveillance-vehicules.git

❌ Erreur : "Authentication failed"
✅ Solution :
   - Assurez-vous d'utiliser un Personal Access Token
   - Le token doit avoir les permissions "repo"
   - N'utilisez PAS votre mot de passe GitHub

❌ Erreur : "file is too large"
✅ Solution :
   git rm --cached fichier-volumineux.pt
   echo "fichier-volumineux.pt" >> .gitignore
   git add .gitignore
   git commit -m "chore: ignore fichier volumineux"
